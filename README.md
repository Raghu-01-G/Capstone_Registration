# SJC Inter Department Cultural Events - Registration

Static website (HTML, CSS, JavaScript) hosted with GitHub Pages.

| File | Purpose |
|------|---------|
| `index.html` | Main page: login + registration form with step-by-step validation |
| `form.html` | Plain registration form (no login, no validation) |
| `style.css` | Styles shared by both pages |
| `script.js` | Login and validation logic (used by `index.html`) |

## Host on GitHub Pages
1. Create a repository and upload all files to the root.
2. Settings -> Pages -> Source: *Deploy from a branch* -> Branch: `main`, folder `/ (root)` -> Save.
3. Open `https://<username>.github.io/<repository>/` after about a minute.
